Build a Sepolia demo that gates ERC-20 transfers through Newton.

Product I want a small wallet UI where I connect MetaMask, enter a recipient and an amount, and send Sepolia USDC (0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238, 6 decimals) only if Newton allows it.

Policy

Allow a transfer(address recipient, uint256 amount) when amount <= 10 USDC (10000000 base units).
Deny anything above that cap.
Cap is a policy parameter I can change later (maxAmount).
No external HTTP oracle and no secrets for this version. WASM can be a stub.
Chain: Ethereum Sepolia (11155111). Intent value is 0. The intent target is the USDC token, not the wrapper.
App contract Wrap the transfer in a Newton PolicyClient. After a successful attestation, pull USDC from the connected wallet (transferFrom) and send it to the recipient. I will approve the wrapper in the UI before the first send.

Frontend A local Next.js page is enough: connect wallet, recipient, amount, optional approve, then evaluate and submit. Keep the Newton API key off the browser. Do not deploy to Vercel.

Scope

Author and locally simulate allow (10 USDC) and deny (10.000001 USDC).
Deploy policy + client on Sepolia only after I confirm.
Run the UI with next dev. Live evaluate / the first attested transfer also need my confirmation.
Do not invent extra rules, a different token, or a relayer. Use credentials already on this machine; never ask me to paste keys into chat.
